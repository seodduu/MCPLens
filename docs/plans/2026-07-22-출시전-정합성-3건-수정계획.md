**Files:**

  `mcp-lens.hooksResume` 명령

### 설계

**pause의 의미 — 무엇이 멈추고 무엇이 안 멈추나.** 명령 이름이 "Hook 수집 일시 중지"이므로
**코디네이터의 pending 워처/drain만** 멈춘다. `LogWatcher`(transcript 로그 기반 사용축 수집)는
계속 돈다 — 이건 훅이 아니라 별도 수집 경로이고, 멈추면 매트릭스가 통째로 얼어붙는다.

**데이터는 유실되지 않는다.** 중지 중에 발화한 훅 봉투는 `~/.mcplens/inbox/pending`에 그대로 쌓인다.
재개 시 `startDraining()`의 ready-후 1회 drain이 밀린 봉투를 전부 흡수한다(기존 동작).
알림 문구에 이 사실을 담아 사용자가 "데이터가 날아가나?"를 걱정하지 않게 한다.

**pause는 리스 flap을 이겨야 한다.** 확장은 writer 승격 시 `startDraining()`,
강등 시 `stopDraining()`을 호출한다(`extension.ts:211`, `237`). 중지 중에 failover가 나서
재승격되면 `startDraining()`이 다시 불리는데, 여기서 수집이 되살아나면 안 된다.
→ `startDraining()` 자체가 paused일 때 **no-op**이어야 한다. 확장 쪽 가드만으로는 부족하다
(승격 경로가 여러 곳이고, 코어를 직접 쓰는 다른 소비자도 보호받아야 한다).

**core `coordinator.ts` 추가분:**

```ts
  private paused = false;

  /** 훅 수집을 일시 중지한다(세션 한정). pending 봉투는 inbox에 남고 재개 시 흡수된다. 멱등. */
  async pause(): Promise<void> {
    this.paused = true;
    await this.stopDraining();
  }

  /**
   * 일시 중지를 해제한다. 감시 재개는 호출자가 startDraining()으로 한다 —
   * 재개해도 되는지(writer 리스 보유 여부)는 코어가 아니라 확장만 안다. 멱등.
   */
  resume(): void {
    this.paused = false;
  }

  get isPaused(): boolean { return this.paused; }
```

`startDraining()` 최상단에 가드 1줄 추가(멱등성 체크보다 **앞**):

```ts
  async startDraining(): Promise<void> {
    if (this.paused) return;               // ← 추가: 중지 중 승격/재승격이 수집을 되살리지 못한다
    if (this.pendingWatcher) return;
```

`drainInbox()`는 **가드하지 않는다.** 명시적 1회 호출은 명시적 의도이고, 중지 중에는 확장이
이 경로를 부르지 않는다. (가드를 넣으면 진단 명령이 조용히 실패하는 함정이 된다.)

**확장 `pauseDecision.ts` (신규) — 감시 상태의 단일 진실:**

지금 확장은 워처 상태를 승격/강등 두 곳에서 각각 결정한다. pause가 들어오면 결정 입력이
(paused, mode) 2개로 늘어 분기가 흩어진다. 기존 `leaseMode.ts`·`scanDecision.ts`와 같은
**순수 결정 함수** 패턴으로 한 곳에 모은다:

```ts
import type { LeaseMode } from './leaseMode.js';

export type CollectAction = 'start' | 'stop';

/**
 * 훅 pending 감시를 켤지 끌지 결정한다.
 * writer이면서 중지 상태가 아닐 때만 감시한다 — read-only 홀더는 DB에 쓸 수 없고,
 * 중지 상태는 리스 승격보다 우선한다(사용자의 명시적 의사).
 */
export function collectAction(paused: boolean, mode: LeaseMode): CollectAction {
  if (paused) return 'stop';
  return mode === 'writer' ? 'start' : 'stop';
}
```

### 설계

현재 "이미 없음"을 판정하는 정규식이 **세 벌로 흩어져 있고 그중 둘이 틀렸다**:

claude CLI도 `...not found in installed plugins`를 반환한다. 정규식을 각자 고치면 **네 번째 갈래가
