# Wave 8 — R2b: OAuth http 서버 스캔 (인증 필요 서버의 비용 축 편입)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** vercel처럼 "인증 필요 — 스킵"으로 남는 http MCP 서버를, 사용자 동의 하의 **1회 OAuth 로그인** 후 스캔 가능하게 한다. 원칙: ①클라이언트가 저장한 토큰은 절대 빌려 쓰지 않는다 — Lens 명의로 정식 발급 ②**스캔은 절대 인터랙티브해지지 않는다** — 로그인은 별도의 명시적 행위이고, 스캔은 저장된 토큰이 있으면 쓰고 없으면 지금처럼 스킵.

**설계 근거 (실기기 확인, 2026-07-20):** 설치된 SDK(`@modelcontextprotocol/sdk`)의 `client/auth.js`가 `OAuthClientProvider` 인터페이스(동적 클라이언트 등록·PKCE·토큰 갱신 포함)를 제공하고, `StreamableHTTPClientTransport`가 `authProvider` 옵션을 받는다. 우리는 이 인터페이스의 **구현체(토큰 저장·리다이렉트 처리)**만 만들면 된다. **설치된 SDK 버전의 .d.ts가 진실** — 계획서의 메서드명 추정과 다르면 SDK에 맞춘다.

## 1. Wave 8A — Task 26: core OAuth 엔진 [메인]

**Files:**
- Create: `packages/core/src/scanner/oauth.ts`, `packages/core/test/scanner/oauth.test.ts`
- Modify: `packages/core/src/paths.ts` (`oauthDir()` 추가), `packages/core/src/scanner/scanner.ts` (http 분기에 저장 토큰 자동 첨부), `packages/core/src/index.ts` (export)

**Interfaces (Task 27·28이 소비하는 계약):**

```ts
// oauth.ts
export interface StoredOAuth {
  serverName: string;
  serverUrl: string;
  clientInformation?: unknown;  // 동적 등록 결과 (SDK 타입 그대로 직렬화)
  tokens?: unknown;             // access/refresh 토큰 (SDK 타입 그대로 직렬화)
  updatedAt: string;
}
/** ~/.mcplens/oauth/<serverName>.json — 파일 모드 0600 */
export function loadStoredOAuth(serverName: string): StoredOAuth | null;
export function saveStoredOAuth(data: StoredOAuth): void;
export function clearStoredOAuth(serverName: string): void;
/** 저장 토큰이 있는 http spec에 쓸 SDK Provider 생성 (비인터랙티브 — redirect 요구 시 throw) */
export function storedTokenProvider(spec: McpServerSpec): OAuthClientProvider | null;

/** 인터랙티브 로그인 전체 플로우. openUrl은 호스트가 주입 (CLI: 셸 open / 확장: vscode.env.openExternal).
 *  내부: 127.0.0.1 임시 포트 콜백 서버 기동 → SDK 인증 플로우(동적 등록+PKCE) →
 *  authorization code 수신 → 토큰 교환 → saveStoredOAuth. 타임아웃 기본 120초. */
export function authenticateServer(
  spec: McpServerSpec,
  opts: { openUrl: (url: string) => void | Promise<void>; timeoutMs?: number },
): Promise<void>;
```

**구현 지침:**
- SDK `OAuthClientProvider`의 실제 요구 멤버(redirectUrl, clientMetadata, clientInformation(), saveClientInformation(), tokens(), saveTokens(), redirectToAuthorization(), codeVerifier()/saveCodeVerifier() 등)는 **설치된 `client/auth.d.ts`를 읽고 정확히** 맞출 것. `StreamableHTTPClientTransport`에 `{ authProvider }` 옵션으로 전달.
- 콜백 서버: Node `http.createServer`를 127.0.0.1 임시 포트(listen(0))에 — 수신 후 "로그인 완료, 창을 닫으세요" HTML 응답하고 즉시 close.
- `clientMetadata.client_name`은 `"MCP Lens"` — 서버의 동의 화면에 Lens 명의가 표시되게 (자격증명 원칙).
- 토큰 파일 보안: `oauthDir()` = `path.join(lensHome(), 'oauth')`, `mkdirSync(recursive)` 후 `writeFileSync(..., { mode: 0o600 })`. 평문 저장의 한계는 README/리포트에 정직하게 명시 (키체인은 네이티브 의존이라 제약 3 위반 — 의도적 배제).
- scanner.ts http 분기: `storedTokenProvider(spec)`이 non-null이면 transport에 첨부. 첨부했는데도 인증 실패(토큰 만료+갱신 실패)면 기존 `auth-required` 에러에 `token-expired` 힌트 추가.
- **스캔 경로는 여전히 비인터랙티브**: storedTokenProvider의 `redirectToAuthorization`은 즉시 throw — 스캔 중 브라우저가 열리는 일은 없다.

**테스트 (실 OAuth 서버 없이 — 순수/루프백):**
- 토큰 저장소 왕복·삭제·파일 모드 0600 확인 (임시 디렉토리, `LENS_HOME` 오버라이드 또는 경로 주입)
- `storedTokenProvider`: 저장 데이터 없으면 null / 있으면 tokens() 반환 / redirectToAuthorization은 throw
- 콜백 서버: 임시 포트에 기동 → `fetch('http://127.0.0.1:PORT/callback?code=abc&state=...')` → code가 플로우에 전달되는지 (authenticateServer를 콜백 수신부만 분리 테스트 가능하게 내부 함수 `waitForCallback(port)`로 쪼갤 것)
- 전체 인터랙티브 플로우는 유닛 불가 — 8C 스모크 (계획서에 명시)

## 2. Wave 8B — Task 27: CLI auth 커맨드 [T1]

**Files:** `packages/cli/src/main.ts`, `packages/cli/src/auth-open.ts`(신규 — 플랫폼별 URL 열기), `packages/cli/test/`

- `mcp-lens auth <serverName>`: `collectAllSpecs()`에서 이름으로 spec 찾기(http만 허용, 없으면/stdio면 안내 후 exit 1) → `authenticateServer(spec, { openUrl })` → 성공 시 즉시 해당 서버 1개 스캔·적재 → `"vercel: 로그인 완료, 툴 N개 · M토큰"`.
- `openUrl`: macOS `open`, Linux `xdg-open`, Windows `start` — `child_process.spawn` 분기 (순수 함수로 커맨드 선택 분리 → 유닛테스트).
- `mcp-lens auth --clear <serverName>`: `clearStoredOAuth` 호출.
- scan 출력의 인증 스킵 안내를 업데이트: `인증 필요 — 스킵 (npx mcp-lens auth vercel 로 로그인)`.
- 테스트: openUrl 커맨드 선택(3 플랫폼), auth 대상 검증 로직(이름 없음/stdio/http)을 순수 함수로 추출해 유닛. 실 네트워크 금지.
- Commit `feat(cli): auth command (oauth login + immediate scan)`

## 3. Wave 8B — Task 28: 확장 인증 알림 [T2]

**Files:** `packages/extension/src/autoScan.ts`, `packages/extension/src/authDecision.ts`(신규 — 순수), `packages/extension/test/authDecision.test.ts`

- runScan 결과에서 auth-required 실패 서버 목록을 모아, 스캔 완료 후 알림 1개:
  `"MCP 서버 N개(vercel)는 로그인이 필요합니다. 브라우저에서 로그인할까요? (Lens 명의로 접근 권한을 요청합니다)"` — 버튼 `[로그인] [나중에] [이 서버는 묻지 않음]`.
- `[로그인]` → 서버별 `authenticateServer(spec, { openUrl: (u) => vscode.env.openExternal(vscode.Uri.parse(u)) })` → 성공 시 해당 서버 재스캔 → refresh.
- `[이 서버는 묻지 않음]` → `mcpLens.authIgnore: string[]` 설정에 서버명 추가 (package.json에 설정 선언). 알림 조건에서 제외.
- 순수 로직 분리: `decideAuthPrompt({ failedServers, ignoreList })` → `{ kind: 'skip' } | { kind: 'prompt', targets }` — 유닛테스트 4케이스 이상 (빈 목록/전부 ignore/일부 ignore/신규).
- 토큰 만료(`token-expired` 힌트) 서버도 같은 알림 경로로 (재로그인 유도).
- Commit `feat(extension): auth-required notification with oauth login flow`
