```ts
export interface McpServerSpec {
  name: string;
  /** stdio 서버: 실행 커맨드. http 서버: undefined */
  command?: string;
  args?: string[];
  env?: Record<string, string>;
  /** http 서버: 접속 URL. stdio 서버: undefined */
  url?: string;
}
export function specTransport(s: McpServerSpec): 'stdio' | 'http' | 'unknown';
// command 있으면 'stdio', 없고 url 있으면 'http', 둘 다 없으면 'unknown'
```

`CollectResult.skipped`의 의미 변경: **"stdio가 아니라 스킵" → "전송 판별 불가(unknown)라 스킵"**. http 서버는 이제 `specs`에 포함된다(스캔 가능해졌으므로).

## 3. Wave 7B — Task 24: http 전송 스캔 [T2]

**Files:**

**구현 명세:**

```ts
// scanner.ts — scanServer가 전송을 판별해 분기
import { StreamableHTTPClientTransport } from '@modelcontextprotocol/sdk/client/streamableHttp.js';
// specTransport(spec)이 'http'면:
const transport = new StreamableHTTPClientTransport(new URL(spec.url!));
// 이후 connect → listTools → 토크나이즈는 기존 경로 공유 (중복 금지 — 전송 생성만 분기)
// 'unknown'이면 즉시 throw new Error(`unknown transport: ${spec.name}`)
```

- 인증 요구(HTTP 401/403 또는 SDK OAuth 에러)는 **정상 실패로 분류**: `throw`하되 메시지에 `auth-required`를 포함시켜 표면이 "인증 필요 — 스킵(R2b 로드맵)"으로 안내할 수 있게 한다.
- 타임아웃 15초 동일 적용.

- [ ] Step 1: 실패하는 테스트 — **로컬 루프백 http MCP 서버를 테스트 안에서 기동**해 실검증:

```ts
// scan-http.test.ts 골격 — SDK 서버를 127.0.0.1:0(임시 포트)에 띄운다
import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StreamableHTTPServerTransport } from '@modelcontextprotocol/sdk/server/streamableHttp.js';
// http.createServer + transport.handleRequest 연결, listen(0) → 실제 포트 획득
it('http 서버를 tools/list로 스캔해 정의 토큰을 계산한다', async () => {
  const { url, close } = await startLocalHttpMcp([
    { name: 'echo', description: 'Echo back text for http scan test' }]);
  try {
    const defs = await scanServer({ name: 'httptest', url });
    expect(defs).toHaveLength(1);
    expect(defs[0].serverName).toBe('httptest');
    expect(defs[0].definitionTokens).toBeGreaterThan(0);
  } finally { await close(); }
});
it('unknown 전송은 throw', async () => {
  await expect(scanServer({ name: 'x' })).rejects.toThrow(/unknown transport/);
});
```

SDK의 `StreamableHTTPServerTransport` 사용법은 설치된 `node_modules/@modelcontextprotocol/sdk`의 타입 선언·예제를 직접 확인해 맞춘다 (버전에 따라 세션 관리 옵션이 다름 — **설치된 버전이 진실**). stateless 모드(`sessionIdGenerator: undefined`)가 테스트에 단순하다.
