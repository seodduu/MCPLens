### Step 2: evidence.ts — confidencePhrase 분리

현행 `confidencePhrase`는 `' — '` 접두사를 문자열에 박아 반환한다(`evidence.ts:222`).
알맹이만 내는 함수를 새로 만들고, 기존 함수는 그것을 감싸 **현행과 동일하게** 유지한다.

```ts
/** 확신 꼬리말의 알맹이 (구분자 없음). 리포트 렌더러가 이것을 직접 쓴다 */
export function confidenceCaveat(
  confidence: RecommendationConfidence,
  ev: RecommendationEvidence,
): string {
  const days = ev.observedDays == null ? '' : `/${ev.observedDays}일`;
  if (confidence === 'low')
    return `관찰 부족(${ev.observedSessions}세션${days}), `
      + `${HIGH_CONFIDENCE_SESSIONS}세션 누적 시 확정. 아직 확정 권고 아님`;
  if (confidence === 'medium' && ev.lastCalledAt != null)
    return `마지막 호출 ${ev.lastCalledAt.slice(0, 10)}, 저빈도 툴일 수 있음. `
      + `삭제보다 지연 로딩 유지 검토`;
  if (confidence === 'medium')
    return `${ev.observedSessions}세션${days} 관찰, 추가 관찰 시 확정`;
  return `${ev.observedSessions}세션${days} 관찰, `
    + `누적 부담 ${ev.totalObservedCost ?? 0}토큰. 설정 한 줄로 복구 가능`;
}

/** @deprecated 리포트 렌더러는 confidenceCaveat를 쓴다. reason 결합 호환용 */
export function confidencePhrase(c: RecommendationConfidence, ev: RecommendationEvidence): string {
  return ` — ${confidenceCaveat(c, ev)}`;
}
```

기존 `evidence.test.ts`가 `confidencePhrase`를 검증하고 있으면 **그대로 둔다** — 통과해야 한다.

### Step 3: engine.ts — recommend()가 parts를 조립

`recommend()`의 각 분기가 `reason` 문자열을 직접 만드는 대신 parts를 만들고,
공통 결합 함수로 `reason`을 생성한다.

```ts
/** parts → 현행 reason 문자열. 구분자 규칙이 여기 한 곳에만 있다 */
export function joinReason(p: RecommendationReason): string {
  const head = p.serverBasis == null ? p.basis : `${p.serverBasis} ${p.basis}`;
  const body = p.effect == null ? head : `${head}${head.endsWith('—') ? ' ' : ' — '}${p.effect}`;
  return p.caveat == null ? body : `${body} — ${p.caveat}`;
}
```

> **주의:** 위 결합 규칙은 **현행 문자열을 재현하도록 조정해야 한다.**
> 현행 `filter-server` reason은
> `` `서버 ${name}의 ${total}툴 중 ${used}개만 사용 — 툴 필터링 권장. ${sizePhrase} ${pollutionSuffix}${tail}` ``
> 형태이고 `sizePhrase`·`pollutionSuffix`·`tail`의 공백/구분자가 분기마다 다르다.
> Step 1의 동일성 테스트가 그린이 될 때까지 `joinReason`과 parts 경계를 조정하라.
> **계획서의 결합 규칙보다 기존 문자열이 진실이다.**

분기별 parts 매핑:

| 분기 | basis | serverBasis | effect | caveat |
|---|---|---|---|---|
| filter-server | `정의 N토큰, 호출 0회` 상당 + pollutionSuffix | `서버 X의 N툴 중 M개만 사용 — 툴 필터링 권장.` | sizePhrase | confidenceCaveat |
| remove | `정의 N토큰, 호출 0회` + pollutionSuffix | null | sizePhrase | confidenceCaveat |
| inspect | `N회 중 M회 실패(P%), 실패 응답 K토큰 낭비` | null | `점검·대체 권장` | null |
| keep | `N회 호출됨` | null | null | null |
| unknown | `정의 토큰 미확보 (스캐너 미커버)` | null | null | null |
