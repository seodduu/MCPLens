# Wave 3 Task 13 품질 보정 프롬프트

## 목표

Task 13 quality review의 두 지적을 현재 HEAD에서 재현 테스트로 판정하고 실제 결함만 수정한다.

- Claude 전역 설정 mutation은 동시 요청·외부 수정 사이에서 사용자 원문을 덮어쓰지 않는다.
- 분석 취소가 실행 중인 inference CLI child까지 전달되어 종료되고, 취소 결과는 저장되지 않는다.
- 현재 코드와 회귀 테스트가 이미 계약을 충족하면 기능 코드를 바꾸지 않고 file:line과 실행 출력으로 오래된 지적임을 보고한다.

## 경계와 검증

- 허용 Files: `packages/core/src/actions/claude.ts`, `packages/core/test/actions/claude.test.ts`, `packages/core/src/dependency/analyzer.ts`, `packages/core/test/dependency/analyzer.test.ts`, `packages/extension/src/analysisCoordinator.ts`, `packages/extension/src/inferenceCli.ts`, `packages/extension/src/extension.ts`, `packages/extension/test/analysisCoordinator.test.ts`, `packages/extension/test/inferenceCli.test.ts`.
- 공유 계약인 `packages/core/src/types.ts`, `packages/core/src/store/schema.sql`, 루트 설정은 수정하지 않는다.
- 실제 home 설정·공유 DB·MCP 서버·Task 14 E2E는 범위 밖이다. memFs·fixtures·`:memory:` DB만 사용한다.
- Claude apply/restore는 경로별 lease, UUID 포함 temporary/backup, fsync 뒤 rename 직전 fingerprint 재검증을 지킨다. 불일치면 temporary를 정리하고 사용자 파일을 교체하지 않는다.
- `AbortSignal`은 coordinator → analyzer → runner → `runInference`로 그대로 전달한다. abort는 child를 kill하고 `cancelled`를 반환하며 failed cache와 `store.save()`를 남기지 않는다.

자식 완료 메시지를 받으면 사용자에게 agent ID·상태·변경 파일·검증 결과·report 경로·다음 조치를 commentary로 보고한다. report, 허용 Files diff, 테스트 결과를 검토하기 전에는 통합하지 않는다.
