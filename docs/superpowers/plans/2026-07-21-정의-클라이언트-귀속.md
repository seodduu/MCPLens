# 정의의 클라이언트 귀속 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 툴 정의가 어느 클라이언트 설정에서 왔는지 저장해, 스캔된 전 정의가 모든 클라이언트에 조인되는 문제를 없앤다.

**Architecture:** `tool_definitions`(정의 토큰 = 서버의 속성)는 그대로 두고 `client_servers` 매핑 테이블을 새로 만든다. 스캐너가 이미 아는 설정 출처를 살려 저장하고, 엔진이 클라이언트별로 정의를 필터링한다. `EngineInput`의 새 필드는 **선택**이라 넘기지 않으면 기존 동작이 그대로 유지된다.

**Tech Stack:** TypeScript, vitest, sql.js, npm workspaces

**설계 문서:** `docs/superpowers/specs/2026-07-21-정의-클라이언트-귀속-design.md`

## Global Constraints

- `packages/core/src/types.ts`는 **수정 금지** (공유 계약). 이 작업은 `types.ts` 변경 없이 완결된다.
- `packages/core/src/store/schema.sql`은 공유 계약이나 이 작업에서 **테이블 추가만** 허용한다. 기존 테이블의 컬럼·PK를 바꾸지 마라.
- `packages/dashboard/`는 동결 표면이다. 수정하지 마라 — 선택 필드라 안 넘기면 현재와 동일하게 동작한다.
- core에서 `vscode` import 금지.
- 경로는 `os.homedir()` + `path.join()` (`~` 하드코딩 금지).
- 원본 클라이언트 설정 파일은 **읽기 전용**이다.
- 유닛테스트는 픽스처 + `:memory:` DB만 사용한다 (터미널 병렬 안전).
- 테스트 실행은 저장소 루트에서 `npx vitest run <경로>`.
- 소스 종류 → ClientId 매핑은 이 값을 그대로 쓴다:
  `claude-user` → `claude-code`, `claude-project` → `claude-code`,
  `codex` → `codex`, `gemini` → `gemini-cli`.

```typescript
// packages/core/src/scanner/attribution.ts
// 설정 소스 → 클라이언트 귀속. IO 없는 순수 매핑이라 단독 테스트한다.
// 설계: docs/superpowers/specs/2026-07-21-정의-클라이언트-귀속-design.md
import type { ClientId } from '../types.js';

/** 설정 소스 종류 → 클라이언트. claude-user·claude-project는 같은 클라이언트로 접힌다. */
export function clientForSourceKind(kind: string): ClientId | null {
  switch (kind) {
    case 'claude-user':
    case 'claude-project':
      return 'claude-code';
    case 'codex':
      return 'codex';
    case 'gemini':
      return 'gemini-cli';
    default:
      return null;
  }
}

export interface SourceRead {
  kind: string;
  /** 이 소스에서 발견한 서버 이름들 */
  servers: string[];
  /** 'missing'(파일 없음)은 정상 — 서버 0개로 취급한다. 'error'만 관찰 실패다. */
  failed: 'none' | 'missing' | 'error';
}

/**
 * 소스별 읽기 결과 → (서버 → 클라이언트 집합) 귀속과, 매핑을 통째로 교체해도 되는
 * 클라이언트 집합.
 *
 * 교체 가능 판정: 한 클라이언트의 소스 중 'error'가 하나라도 있으면 제외한다.
 * 읽기 실패를 "서버 없음"으로 해석하면 그 클라이언트의 정의가 화면에서 통째로 사라진다.
 * 파일 부재는 정상이므로(프로젝트별 .mcp.json은 대부분 없다) 교체 대상에 남긴다.
 */
export function attributeServers(reads: SourceRead[]): {
  attribution: Map<string, Set<ClientId>>;
  replaceable: Set<ClientId>;
} {
  const attribution = new Map<string, Set<ClientId>>();
  const seen = new Set<ClientId>();
  const broken = new Set<ClientId>();

  for (const r of reads) {
    const client = clientForSourceKind(r.kind);
    if (client === null) continue;
    seen.add(client);
    if (r.failed === 'error') broken.add(client);
    for (const name of r.servers) {
      let set = attribution.get(name);
      if (set === undefined) { set = new Set(); attribution.set(name, set); }
      set.add(client);
    }
  }

  const replaceable = new Set<ClientId>();
  for (const c of seen) if (!broken.has(c)) replaceable.add(c);
  return { attribution, replaceable };
}
```

```typescript
/** 모든 소스 파일을 읽어 병합 (읽기 전용, 없는 파일은 무시). 우선순위: claude-user > claude-project > codex > gemini (이름 충돌 시 먼저 온 것). */
export function collectAllSpecs(): CollectResult & {
  sources: ConfigSource[];
  attribution: Map<string, Set<ClientId>>;
  replaceable: Set<ClientId>;
} {
  const sources = configSources();
  const priority: Record<string, number> = {
    'claude-user': 0,
    'claude-project': 1,
    codex: 2,
    gemini: 3,
  };
  const ordered = [...sources].sort((a, b) => (priority[a.kind] ?? 99) - (priority[b.kind] ?? 99));

  const byName = new Map<string, McpServerSpec>();
  const skippedSet = new Set<string>();
  const reads: SourceRead[] = [];

  for (const source of ordered) {
    let text: string;
    try {
      text = fs.readFileSync(source.filePath, 'utf-8');
    } catch (err) {
      // 파일 부재는 정상(프로젝트별 .mcp.json은 대부분 없다) — 관찰 실패와 구분한다.
      const missing = (err as NodeJS.ErrnoException)?.code === 'ENOENT';
      reads.push({ kind: source.kind, servers: [], failed: missing ? 'missing' : 'error' });
      continue;
    }
    const { specs, skipped } = collectFromSource(source.kind, text);
    reads.push({ kind: source.kind, servers: specs.map((s) => s.name), failed: 'none' });
    for (const spec of specs) {
      if (!byName.has(spec.name)) byName.set(spec.name, spec);
    }
    for (const name of skipped) skippedSet.add(name);
  }

  const { attribution, replaceable } = attributeServers(reads);
  return { specs: [...byName.values()], skipped: [...skippedSet], sources,
    attribution, replaceable };
}
```

```typescript
import { describe, it, expect } from 'vitest';
import { LensStore } from '../../src/store/store.js';

const attr = (pairs: Array<[string, ClientId[]]>) =>
  new Map(pairs.map(([name, clients]) => [name, new Set(clients)]));

describe('client_servers', () => {
  it('빈 DB에서는 빈 맵을 돌려준다', async () => {
    const store = await LensStore.open(':memory:');
    expect(store.serversByClient().size).toBe(0);
  });

  it('귀속을 저장하고 클라이언트별로 되읽는다', async () => {

    store.upsertClientServers(
      attr([['notion', ['claude-code']], ['node_repl', ['codex']]]),
      new Set<ClientId>(['claude-code', 'codex']));
    const m = store.serversByClient();

      attr([['deepwiki', ['claude-code', 'codex']]]),
      new Set<ClientId>(['claude-code', 'codex']));
    const m = store.serversByClient();
```

```typescript
    replaceable: Set<ClientId>): void {

    for (const [serverName, clients] of attribution)
      for (const client of clients) {
```
