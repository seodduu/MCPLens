# 단일 Writer 리스 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 여러 프로세스가 같은 `lens.db`에 동시에 써서 발생하는 lost-update를, 단일 writer 리스로 구조적으로 차단한다.

**Architecture:** inbox의 검증된 크로스-프로세스 리스 원시를 `lease.ts`로 추출하고 `renew`를 추가한다. `LensStore.save()`에 리스 소유 가드를 달아 비홀더의 쓰기를 `StaleWriterError`로 거부하고, 비홀더는 `reload()`로 화면만 최신화한다. 확장은 activate 때 리스를 획득하면 writer(워처·drain·스캐너), 못 얻으면 read-only로 동작한다.

**Tech Stack:** TypeScript, sql.js(WASM, 네이티브 금지), 순수 node:fs 리스, VS Code Extension API, vitest.

## Global Constraints

- 공유 계약 파일 수정 금지: `packages/core/src/types.ts`, `packages/core/src/store/schema.sql`, 루트 설정.
- core에서 `vscode` import 금지. 네이티브 애드온 금지(sql.js 유지). 경로는 `os.homedir()`+`path.join`, `~` 하드코딩 금지.
- 유닛 테스트는 고유 임시 디렉토리 + `:memory:`/임시 파일만 사용(병렬 안전). 실기기 자원 금지.
- 리스는 순수 fs(디렉토리 rename 기반 원자적 배타 생성). 설계: `docs/superpowers/specs/2026-07-22-단일-writer-리스-design.md`(진실 원천).
- **save 순서 불변식**: 인박스 drain은 각 delivery를 `DB 쓰기(save) → markProcessed` 순으로 처리한다. `save()`가 `StaleWriterError`를 던지면 그 delivery는 `markProcessed`에 도달하지 않고 pending으로 남아야 한다(유실 0).
- TTL/갱신: DB writer 리스 `ttlMs=30_000`, 갱신 주기 `10_000`. read-only mtime 폴링 `4_000`.

신규 공개 API 코드:

```ts
// packages/core/src/ingest/lease.ts
import { mkdirSync, writeFileSync, renameSync, rmSync, readFileSync, existsSync, statSync } from 'node:fs';
import { join } from 'node:path';
import { createHash, randomUUID } from 'node:crypto';

export interface Lease { token: string; expiresAt: number }

// ── 이동해 온 저수준 (installLease/readLease/takeOverLease/lockInstanceToken/reapingPath/isBusy/isCode) ──
// (inbox.ts에서 verbatim 이동. Lease 타입만 위 정의를 사용.)

/** 한 번 시도: 설치 성공 또는 만료 리스 인수 후 설치. 유효 홀더가 있으면 null. */
export function acquireLease(lockPath: string, ttlMs: number, nowMs: () => number = () => Date.now()): Lease | null {
  const now = nowMs();
  const lease: Lease = { token: randomUUID(), expiresAt: now + ttlMs };
  if (installLease(lockPath, lease)) return lease;
  const current = readLease(lockPath);
  if (current && current.expiresAt <= now && takeOverLease(lockPath, current.token)) {
    const retry: Lease = { token: randomUUID(), expiresAt: nowMs() + ttlMs };
    if (installLease(lockPath, retry)) return retry;
  }
  return null;
}

/** 내가 여전히 홀더면 만료 연장(원자적 owner.json 교체). 인수당했으면 null. */
export function renewLease(lockPath: string, token: string, ttlMs: number, nowMs: () => number = () => Date.now()): Lease | null {
  const current = readLease(lockPath);
  if (!current || current.token !== token) return null;
  const renewed: Lease = { token, expiresAt: nowMs() + ttlMs };
  const tmp = join(lockPath, `.owner.${randomUUID()}.tmp`);
  try {
    writeFileSync(tmp, JSON.stringify(renewed), { mode: 0o600 });
    renameSync(tmp, join(lockPath, 'owner.json'));
  } catch (error) {
    try { rmSync(tmp, { force: true }); } catch { /* ignore */ }
    if (isCode(error, 'ENOENT')) return null; // 락 디렉토리 사라짐(인수됨)
    throw error;
  }
  const after = readLease(lockPath);
  return after && after.token === token ? after : null;
}

/** 내 토큰일 때만 해제하고 흔적 정리. */
export function releaseLease(lockPath: string, token: string): void {
  if (readLease(lockPath)?.token !== token) return;
  const reaping = reapingPath(lockPath, token);
  try {
    renameSync(lockPath, reaping);
    rmSync(reaping, { recursive: true, force: true });
  } catch (error) {
    if (!isCode(error, 'ENOENT') && !isBusy(error)) throw error;
  }
}
```

생성자에 SQL 팩토리를 보관(reload용). 현재 `private constructor(private db: Database, private filePath: string) {}` → SQL 추가:

```ts
import initSqlJs, { type Database, type SqlJsStatic } from 'sql.js';
// ...
export class StaleWriterError extends Error {
  constructor() { super('LensStore: writer lease lost; refusing to persist'); this.name = 'StaleWriterError'; }
}

export class LensStore {
  private writeGuard: (() => boolean) | null = null;
  private constructor(private db: Database, private filePath: string, private sql: SqlJsStatic) {}

  static async open(filePath: string): Promise<LensStore> {
    const SQL = await initSqlJs();
    const db = filePath !== ':memory:' && existsSync(filePath)
      ? new SQL.Database(readFileSync(filePath)) : new SQL.Database();
    db.exec(SCHEMA); migrate(db);
    return new LensStore(db, filePath, SQL);
  }

  setWriteGuard(fn: (() => boolean) | null): void { this.writeGuard = fn; }

  reload(): void {
    if (this.filePath === ':memory:' || !existsSync(this.filePath)) return;
    this.db.close();
    this.db = new this.sql.Database(readFileSync(this.filePath));
    this.db.exec(SCHEMA); migrate(this.db);
  }
```

`save()` 상단 가드 추가(:memory: 조기 반환 뒤):

```ts
  save(): void {
    if (this.filePath === ':memory:') return;
    if (this.writeGuard && !this.writeGuard()) throw new StaleWriterError();
    mkdirSync(dirname(this.filePath), { recursive: true });
    const tmp = this.filePath + '.tmp';
    writeFileSync(tmp, Buffer.from(this.db.export()));
    renameSync(tmp, this.filePath);
  }
```

> 가드가 던지면 `transaction()`의 `commit()` 안에서 발생하므로, `transaction`이 예외 시 롤백하도록 되어 있는지 확인한다(현 `transaction`은 action 실패 시 롤백하지만 commit 실패 경로도 예외를 전파해야 함). 필요 시 `commit()`에서 save 실패를 그대로 전파(현재도 전파됨).

```ts
// packages/extension/src/writerLease.ts
import { acquireLease, renewLease, releaseLease, type Lease } from '@mcp-lens/core';

interface LeaseDeps {
  acquire: (lockPath: string, ttlMs: number) => Lease | null;
  renew: (lockPath: string, token: string, ttlMs: number) => Lease | null;
  release: (lockPath: string, token: string) => void;
  setInterval: (fn: () => void, ms: number) => ReturnType<typeof setInterval>;
  clearInterval: (h: ReturnType<typeof setInterval>) => void;
}

const DEFAULT_DEPS: LeaseDeps = {
  acquire: acquireLease, renew: renewLease, release: releaseLease,
  setInterval: (fn, ms) => setInterval(fn, ms),
  clearInterval: (h) => clearInterval(h),
};

export class WriterLeaseManager {
  private lease: Lease | null = null;
  private timer: ReturnType<typeof setInterval> | null = null;
  private readonly ttlMs: number;
  private readonly renewMs: number;
  private readonly deps: LeaseDeps;

  constructor(private lockPath: string, opts: { ttlMs?: number; renewMs?: number; deps?: LeaseDeps } = {}) {
    this.ttlMs = opts.ttlMs ?? 30_000;
    this.renewMs = opts.renewMs ?? 10_000;
    this.deps = opts.deps ?? DEFAULT_DEPS;
  }

  tryAcquire(): boolean {
    this.lease = this.deps.acquire(this.lockPath, this.ttlMs);
    return this.lease !== null;
  }

  isHolder(): boolean { return this.lease !== null; }

  startHeartbeat(onLost: () => void): void {
    if (this.timer) return;
    this.timer = this.deps.setInterval(() => {
      if (!this.lease) return;
      const renewed = this.deps.renew(this.lockPath, this.lease.token, this.ttlMs);
      if (renewed) { this.lease = renewed; return; }
      this.lease = null;           // 인수당함 → 즉시 비홀더
      this.stopTimer();
      onLost();
    }, this.renewMs);
  }

  private stopTimer(): void {
    if (this.timer) { this.deps.clearInterval(this.timer); this.timer = null; }
  }

  stop(): void {
    this.stopTimer();
    if (this.lease) { this.deps.release(this.lockPath, this.lease.token); this.lease = null; }
  }
}
```

```ts
import { WriterLeaseManager } from './writerLease.js';
import { dbWriterLockPath } from '@mcp-lens/core';
import { chooseMode } from './leaseMode.js';
import * as fs from 'node:fs';

const lease = new WriterLeaseManager(dbWriterLockPath());
let mode = chooseMode(lease.tryAcquire());
let roPoll: ReturnType<typeof setInterval> | undefined;

function enterWriter() {
  mode = 'writer';
  store!.setWriteGuard(() => lease.isHolder());
  if (roPoll) { clearInterval(roPoll); roPoll = undefined; }
  watcher!.start();
  void coordinator?.drainInbox().then(refresh);
  lease.startHeartbeat(() => enterReadOnly()); // renew 실패 → 강등
}

function enterReadOnly() {
  mode = 'read-only';
  // 쓰기 경로 정지: 워처 stop이 있으면 호출(없으면 이벤트 핸들러 무시). 코디네이터 drain 미호출.
  watcher!.stop?.();
  // mtime 폴링 → 변하면 reload + refresh
  let lastMtime = 0;
  if (!roPoll) roPoll = setInterval(() => {
    try {
      const m = fs.statSync(dbPath()).mtimeMs;
      if (m !== lastMtime) { lastMtime = m; store!.reload(); refresh(); }
    } catch { /* 파일 없음/일시 오류 무시 */ }
    if (lease.tryAcquire()) enterWriter(); // 홀더 죽었으면 승격
  }, 4_000);
}

if (mode === 'writer') enterWriter(); else enterReadOnly();

ctx.subscriptions.push({ dispose: () => { if (roPoll) clearInterval(roPoll); lease.stop(); } });
```

기존 무조건 `watcher.start()`/`coordinator.drainInbox()` 호출은 `enterWriter()`로 이관하고, 기존 위치에서 제거한다. `refresh`는 두 모드 공통(읽기라 안전). 상태바/트리는 어느 모드든 store에서 읽어 표시.

> `watcher.stop`이 없으면 read-only 진입 시 `watcher.start()`를 애초에 부르지 않는 것으로 충분하다(강등 시엔 이후 이벤트가 와도 `setWriteGuard`가 `StaleWriterError`로 쓰기를 차단). 실제 `LogWatcher` API를 확인해 `stop`이 있으면 호출, 없으면 생략.
