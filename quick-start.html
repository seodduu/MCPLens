Quick Start ​

By the end of this page you will have MCP Lens installed and will have seen your own cost x usage matrix: the table that lines up how many tokens each MCP tool definition costs against how often it is actually called.

Requirements ​

  • Node.js 20 or later.
  • VS Code 1.90 or later, only if you use the VS Code extension.

Install ​

Pick one path. The VS Code extension is the main distribution: scanning, hook installation, reports and dependency analysis all live inside it, so no separate CLI install is needed. The CLI is optional and useful for scripting or a terminal-only workflow. The extension path's last line installs the .vsix that npm run package just built; replace <version> with the version printed in that step's output (it matches the file that appears under packages/extension/).

bash
git clone https://github.com/seodduu/MCPLens.git
cd MCPLens
npm install
npm run build
npm run package -w mcp-context-lens     # creates packages/extension/*.vsix
code --install-extension packages/extension/mcp-context-lens-<version>.vsix
bash
git clone https://github.com/seodduu/MCPLens.git
cd MCPLens
npm install
npm run build
npm link -w @mcp-lens/cli      # only if you want mcp-lens outside the repository

WARNING

An unrelated package named mcp-lens exists in the registry. Running plain npx mcp-lens downloads and runs that third-party package whenever there is no local bin. Always use the npx --no-install mcp-lens form, or call the linked bin directly as above.

Verify ​

md
Reopen VS Code. The MCP Lens icon appears in the activity bar, and the onboarding walkthrough opens
automatically.
bash
npx --no-install mcp-lens --help

The CLI command prints, among other lines:

mcp-lens: MCP context accounting tool

Your first audit in 5 minutes ​

Both paths reach the same matrix. The CLI commands below use the npx --no-install mcp-lens form and are run from inside the cloned repository, per the warning above. If you ran the optional npm link step, plain mcp-lens works from anywhere and you can drop the npx --no-install prefix everywhere on this page.

1. Scan your MCP servers ​

md
Run **MCP Lens: Scan MCP Servers** from the Command Palette (`Cmd/Ctrl+Shift+P`). The onboarding
walkthrough's first step runs the same scan, so if you just finished the walkthrough this is
already done.
bash
npx --no-install mcp-lens scan

The scan briefly starts each configured stdio server and calls tools/list on it. It spends no LLM tokens and never edits a client config file, so it is safe to run against a live configuration.

2. Read the cost x usage matrix ​

md
Open the MCP Lens icon in the activity bar and look at the `Cost × Usage Matrix` view. For the same
matrix as a full report page, run **MCP Lens: Show Report** from the Command Palette.
bash
npx --no-install mcp-lens report

The report puts the definition token cost of every tool next to how often it was actually called, and a recommended action per row. Below is the CLI's table form. These are real rows from a run; the loaded/sessions, errorRate and errorTokens columns are cut here for width and the longer reason cells are truncated with an ellipsis, while your own terminal shows every column and each reason sentence in full:

server          tool                                defTokens  calls  respTokens  action         confidence  reason
--------------  ----------------------------------  ---------  -----  ----------  -------------  ----------  ---------------------------------------------------
web-search      web-search_place_search             17251      0      0           remove         medium      definition 17,251 tokens, 0 calls...
knowledge-base  knowledge-base-query-meeting-notes  5929       0      0           filter-server  high        Only 2 of 28 tools used on server knowledge-base...
weather-tools   get_weather                         74         4      83          keep           high        called 4 times

savings: potential=61893 actual=26839 saved=35054

That last line is the number that matters: with everything the report currently sees as removable turned off, saved tokens stop riding along on every prompt.

Next steps ​

You have now seen the matrix. To make calls reflect real usage instead of staying at zero for everything, install the hooks for your client next: Claude Code, Codex, or Gemini CLI. To understand what the columns and actions mean in detail, see Reading Reports. For how the scan and the hooks fit together under the hood, see How It Works.
